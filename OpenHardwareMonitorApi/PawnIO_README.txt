TrafficMonitor 1.86-x.1 hardware monitoring

LibreHardwareMonitorLib 0.9.6 uses PawnIO instead of the vulnerable WinRing0
driver. Before enabling hardware monitoring:

1. Run PawnIO_setup.exe as an administrator.
2. Restart TrafficMonitor.

PawnIO project: https://github.com/namazso/PawnIO.Setup
LibreHardwareMonitor: https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
